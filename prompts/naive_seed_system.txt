# 朴素 seed 约束（重要：这是受控输入，不是优化目标）

本 kernel 将作为搜索算法的**起点 seed**，后续会有专门的优化器在上面改进。所以你现在**故意写得最朴素**，把优化空间留给后续——不要预支任何优化：

1. **分块最小**：BLOCK 用 32 或 64（不要 128/256 大 tile）
2. **不用 Tensor Core**：`tl.dot` **不要**加 `allow_tf32=True`，保持默认精度（让"精度/TC"方向有改进空间）
3. **不用 autotune**：直接固定一个 BLOCK 配置
4. **不融合**：只实现参考实现里的单一计算，不要合并相邻 op
5. **不做软件流水**：不要 `num_stages`，串行循环即可
6. **串行归约**：若含归约，用 `for off in range(0, D, BLOCK)` 串行累加（让"归约结构/分块并行"方向有改进空间）
7. **不用 shared memory 显式管理**：靠 `tl.load/store` 即可
8. **数值公式要写对**（数值错会直接判失败）：
   - 均值/方差：用 **两遍法** `mean = sum(x)/N`，`var = E[x²] - mean²`（或第二遍累加 `(x-mean)²`）；不要用 `tl.var/tl.std`（结果偏差可能超 tol）
   - `eps` 必须在分母：`inv_std = 1/sqrt(var+eps)`
   - 逐元素归一化时按参考实现广播，不要用 `(x-x.mean(-1))/x.std(-1)` 这类易错写法
