## 1. @triton.autotune — 默认不使用，最多 3 个 Config

**默认用 `@triton.jit`，不用 autotune。** 只在以下情况使用 `@triton.autotune`：
- 优化计划明确要求搜索 tile 大小
- 问题维度不固定，需要在运行时根据大小选择 tile

使用 autotune 时 **Config 数量 ≤ 3**。

## 2. Shared Memory 预算

总 shared memory 估算：`(BLOCK_M × BLOCK_K + BLOCK_K × BLOCK_N) × dtype_size × 2 × num_stages`。必须 < 99 KB。

安全方案（fp32, num_stages=3）：
- BLOCK_M=128, BLOCK_N=128, BLOCK_K=32 → ~49 KB ✓
- BLOCK_M=128, BLOCK_N=128, BLOCK_K=64 → ~73 KB ✓
- BLOCK_M=256, BLOCK_N=128, BLOCK_K=32 → ~49 KB ✓
- BLOCK_M=256, BLOCK_N=256, BLOCK_K=64 → ~180 KB ✗

## 3. tl.constexpr 正确用法

`tl.constexpr` 标注的值必须是 kernel 参数，由 host 端 `run()` 传入，**不能在 kernel 内部从运行时 tensor 计算**。

## 4. tl.dot 使用 Tensor Core

`tl.dot(a, b, acc=accumulator, allow_tf32=True)` — 启用 TF32 tensor core。

## 6. 权重加载（Level 2+ 带预训练权重）— 必须缓存，不要照抄 nn.Module

参考实现（reference）现在用 `Model.forward()` 作为 ground truth（`run(x)` 内部 `model.load_state_dict(torch.load(_weights_path))` 调 Model）。但你写 Triton kernel 时：

**绝对不要照抄 nn.Module / Model / load_state_dict**（被 anti_pytorch_check 禁止）。你要用 `torch.load(_weights_path)` 直接加载权重 dict，按 key 取权重。权重 key 对应 Model.__init__ 的 `self.xxx`：
- `self.gemm = nn.Linear(...)` → `_weights['gemm.weight']` / `_weights['gemm.bias']`
- `self.conv = nn.Conv2d(...)` → `_weights['conv.weight']`（+ `conv.bias` 如有）
- `self.bias = nn.Parameter(...)` → `_weights['bias']`
- BatchNorm 还会有 `_weights['bn.running_mean']` / `_weights['bn.running_var']`（如需用 running stats）

**必须缓存权重**（不要每次 run 都 torch.load，每次 load 数百 MB 慢 20×）：

```python
_weights = None
def run(x):
    global _weights
    if _weights is None or str(next(iter(_weights.values())).device) != str(x.device):
        _weights = {k: v.to(x.device) for k, v in torch.load(_weights_path, map_location='cpu', weights_only=True).items()}
    w = _weights['gemm.weight']   # 按 Model.__init__ 的 self.xxx 推断 key
    b = _weights.get('gemm.bias')
    # ... 调 @triton.jit kernel，return 结果
```

如果参考实现是 `def ref(x, weights=None):` 形式（dispatch 子图），`run()` 也用 `def run(x, weights=None):`，直接用 `weights['key']`，无需 `torch.load`。
